## 🚀 Projetos em destaque

### 🎯 [Career Tracker](https://github.com/LuKeT-Dev-Py/career-tracker-python)
Protótipo em Python para acompanhar candidaturas pelo terminal. A versão atual cadastra duas candidaturas, lista os registros e permite editar empresa, cargo e status com validação de entradas.

**O que pratico:** funções, módulos e pacotes, listas e dicionários, laços e tratamento de `ValueError`.

Os dados permanecem em memória durante a execução. O repositório preserva as versões anteriores e documenta a evolução do projeto.

### 💰 [Gerenciador de gastos](https://github.com/LuKeT-Dev-Py/gerenciador-de-gastos-python)
Programa de terminal para registrar, consultar, editar e excluir gastos. Inclui filtros por categoria, ordenação, total acumulado e validação de valores e datas.

**Conceitos presentes:** organização em funções, coleções, tratamento de exceções e formatação de dados. O repositório reúne a versão original e a refatorada; o armazenamento ainda é em memória.

Coleção de projetos menores para aplicar os conteúdos de Python. O primeiro é o **Registro de Estudos**, que registra sessões e consulta o total de minutos estudados.
